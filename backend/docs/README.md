## مقدمه

به مستندات پروژه **Printoo24 Backend** خوش آمدید. این مستندات به صورت جامع و ساختاریافته تمام جنبه‌های پروژه را پوشش می‌دهد و برای توسعه‌دهندگان، مدیران و تیم فنی طراحی شده است.

### 🎯 اهداف این مستندات:
- ✅ ارائه درک کامل از معماری و ساختار پروژه
- ✅ راهنمایی توسعه‌دهندگان جدید برای ورود به پروژه
- ✅ مستندسازی تمام اپلیکیشن‌ها، سرویس‌ها و APIها
- ✅ ایجاد مرجع کامل برای عیب‌یابی و نگهداری
- ✅ کمک به هوش مصنوعی (AI Agents) برای درک بهتر پروژه

### 👥 مخاطبان:
- **توسعه‌دهندگان Backend**: برای درک معماری و توسعه
- **توسعه‌دهندگان Frontend**: برای فهمیدن APIها
- **مدیران پروژه**: برای درک ساختار و قابلیت‌ها
- **تیم DevOps**: برای تنظیمات deployment
- **هوش مصنوعی (AI)**: برای کمک به توسعه و عیب‌یابی

## راهنمای استفاده

### 📖 نحوه مطالعه مستندات:

#### 1. **برای درک کلی پروژه:**
```
1. [00_architecture_overview.md](./00_architecture_overview.md) - خواندن کامل
2. [apps/README.md](./apps/README.md) - مطالعه نمای کلی اپلیکیشن‌ها
3. انتخاب اپلیکیشن مورد نظر و مطالعه مستندات آن
```

#### 2. **برای توسعه یک ویژگی جدید:**
```
1. مطالعه مستندات اپلیکیشن مربوطه
2. بررسی [api/README.md](./api/README.md) برای فهمیدن ساختار API
3. مطالعه [core/README.md](./core/README.md) برای استفاده از مدل‌های پایه
4. بررسی مثال‌های کد در مستندات
```

#### 3. **برای عیب‌یابی:**
```
1. [settings/README.md](./settings/README.md) - بررسی تنظیمات
2. مستندات اپلیکیشن مربوطه - بررسی سرویس‌ها و منطق
3. لاگ‌های مربوطه (در مستندات هر اپلیکیشن ذکر شده)
```

#### 4. **برای استفاده از API:**
```
1. [api/README.md](./api/README.md) - مطالعه کلی API
2. [api/{app}.md](./api/) - مطالعه API مربوطه
3. تست در Swagger UI: http://localhost:8000/api/docs/
```
